# 手書きの数字の画像を作る

ML-Quest で問題 (`problem.yaml`) から書き出した, ML-Found の学習のプロジェクトの骨組み (ML-EDA の画像のデータセットで, 条件の無い拡散のモデルを学ぶ).

## 課題から行動まで

- 字を読む仕組みの試験の担当の課題: 試験に使う手書きの数字の画像が足りず, 集めるのに手間がかかる
- 今のやり方: 人に頼んで手で書いてもらう
- 解けたと言える指標: 試験の画像を集める手間 (時間 / 月. 今 40. 目指す 10. 小さいほど良い)
- 試験の担当が毎月の初めに試験に足す数字の画像を決める
- 機械学習の受け持ち (作る): 手書きの数字の画像
- 成功の基準: 集める手間が月 10 時間以下

## 次にすること

学習する環境には ML-EDA, ML-Found, ML-ModelControl, ML-Inference を 入れる (config の `requires` の機能. 足りなければ学習の前に入れ方を示して止まる. ML-ModelControl と ML-Inference は定義を置くと使う).

1. **データの分析** (ML-EDA): 画像のディレクトリを ML-EDA の `image_folder` で読み, 目的の列の無いレシピ (`task: none`. `recipe_from` の雛形) でこのディレクトリの `outputs/dataset` に書き出す. 検証用の分割は必ず作る. 画像の大きさがそろわないなら, 中身の手順 (`item_steps`) に `resize` (`width`, `height`) を足してそろえる. チャンネルの数 (灰色と色付き) がそろわないなら, `grayscale` (1 チャンネル) か `rgb` (3 チャンネル) を足してそろえる (どちらもそろわないまま ML-EDA は書き出さない)
2. **モデルの作成・選定** (ML-ModelControl): モデルの作成・選定の段階で組んだ定義を, config の `model.spec` の場所 (`models/model.yaml`) に保存する. 入力は雑音を加えた画像 ((バッチ, チャンネル, 高さ, 幅) の float32) と時刻 ((バッチ,) の int64. `dtype: int64` の入力を時刻とみなす) の 2 つ, 出力は画像と同じ形の加えた雑音の予測. 時刻の埋め込みは `op.SinusoidalEmbedding`. 定義が無いうちは, `train.py` の `PlaceholderModel` (印 TODO. 動くことを確かめるだけの小さなモデル) で学習する (config の `model.placeholder: true` がその目印)
3. **学習・評価** (ML-Found): `python train.py`. 画像はデータセットの 0 から 1 の値のまま, 線形の雑音の予定 (config の `diffusion`) で雑音を加え, 加えた雑音を当てる (平均二乗誤差). 重みの指数移動平均 (`trainer.ema.decay`. 既定 0.995) の重みで検証し (更新の回数 (エポック数 × 1 エポックのバッチ数) が 1 / (1 - decay) より十分多くなるようにする. 少ないと初めの重みのままで, 損失がほとんど動かない), 検証用の `valid/loss` が最も良いモデルを選ぶ. 損失 (`valid/loss`) は毎回同じ時刻と雑音で数える. 作った画像の FID は, 最良を選ぶ指標に FID を選んで書き出したときだけ数える. 結果は `outputs/<実験の名前>/<日付>/<時刻>/` に残る (`task.yaml`, テスト用の分割があればテスト用の損失の `evaluations/`, 作った画像 8 件と見比べる検証用の本物の画像 4 件の見本 `samples/`). 損失と FID は今のやり方で数えられないので, 今のやり方とは比べない
4. **推論** (ML-Inference): `model.spec` の場所に定義を置いて学習すると, `train.py` が学習の後に実験の中の `inference/` に雑音だけの推論の一式 (版 5. データセットを持たず, 件数と種で画像を作る. 手順は学習と同じ雑音の予定の `ddim`) を作る. 推論の段階でその `inference/` を登録し, 件数と種を渡すと画像が返る (値はデータセットと同じ 0 から 1 の尺度で, 外に出ることもある). 仮のモデル (`PlaceholderModel`) は定義が無いので一式を作らない
